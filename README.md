Telegram Mini App (GitHub Pages): конспекты, тесты и прогресс.

- Модуль 1 – Экономика организаций (`theory/th01–th12.md`)
- Модуль 2 – Налоги и налогообложение, часть 1 (`theory/nalogi/`)
- Модуль 3 – Бухгалтерский финансовый учёт, часть 1 (`theory/buhuchet/`)

Тесты собраны в `tests.js`, конспекты для приложения – в `theory.js`.
